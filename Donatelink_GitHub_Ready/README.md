# Donatelink Java Project

This is a cleaned and GitHub‑ready version of your **Donatelink** Java project.

## How to Use
1. Download or clone the repo.
2. Open the folder in **Eclipse** → File → Import → Existing Java Project.
3. Make sure your JDK is configured.
4. Run the main class from `src/`.

## Project Structure
- `src/` — Java source code  
- `.gitignore` — ignores Eclipse + Java build files  
- Ready for GitHub upload
